# TechShila

Frontend for TechShila, an inter-hostel tech meet, with problems, team, and leaderboard.

Commits also include work by Aaryan Garg.

## Run

```bash
git clone https://github.com/LifeAyush/techshila.git
cd techshila
npm install
npm start
```

`npm start` runs the app in development (`react-scripts start`). `npm test` runs the test runner (`react-scripts test`).
